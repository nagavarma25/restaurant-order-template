# App Kitchen Menu Maker

A single-page tool that generates a daily menu poster image for The App Kitchen.

- Enter menu items (name + price), order-before time, delivery time, delivery location and WhatsApp number.
- Press **Generate image** to redraw the poster.
- Right-click / long-press the image to save it, or use **Copy image** to paste it into WhatsApp.

Everything runs in the browser (`index.html`), no build step. Hosted with GitHub Pages.
